
# Gym Workout Routine and Protein Intake Tracker

## Project Description
The Gym Workout Routine and Protein Intake Tracker
is a mini project developed using the C programming
language.

It helps users select their daily gym workout routine,
enter workout duration, calculate a daily protein target,
and track protein consumed throughout the day.

## Features
1. Select different gym workout routines.
2. Enter body weight.
3. Track workout duration.
4. Calculate daily protein target.
5. Enter breakfast protein intake.
6. Enter lunch protein intake.
7. Enter dinner protein intake.
8. Enter post-workout protein intake.
9. Calculate total protein consumed.
10. Display remaining protein target.

## Programming Language
C Language

## Software Requirements
- GCC Compiler
- Code::Blocks
- Visual Studio Code
- Online C Compiler

## Concepts Used
- Variables
- Data Types
- If-Else Statements
- Switch Statements
- Arithmetic Operations
- Input and Output Functions

## How to Run

Compile:
gcc gym_tracker.c -o gym_tracker

Run:
./gym_tracker

## Conclusion
This project provides a simple way to manage gym
workout routines and track daily protein intake.
It also helps beginners understand basic C programming
concepts.
